Dollhouse Research Style Guide

This is the active production style system for DollhouseResearch.com.

1) Visual Direction

Principle Production application
Distinctive, not noisy Signature geometry and motif tiles with restrained contrast
Technical clarity Predictable spacing and typography for long-form documentation
Typed content lanes Core, protocol, research, and tooling each carry distinct color identity
Practical hierarchy Clear launch priorities, fast scan cards, and stable navigation

3) Typography

Role Typeface Use
Headings Plus Jakarta Sans Editorial hierarchy and section anchors
Body Manrope Reading paths, docs, and content pages
Utility IBM Plex Mono Labels, metadata, tags, and status signals

4) Components

Component Purpose
Hero + snapshot panel Fast orientation to launch priorities
Motif strip Compact visual tie to Dollhouse icon color language
Typed project cards Color-coded identity for each project class
Timeline list Date-based operational context
Callout Emphasize concrete action or routing
Entry cards Verified news/press coverage with source links and screenshots

5) Motion and Interaction

  • Reveal-on-scroll remains subtle and non-blocking.
  • Mermaid diagrams support zoom and drag-pan.
  • prefers-reduced-motion remains active.

6) Theme Modes

  • Light mode is default and brand-aligned.
  • Dark mode is available in the header toggle.
  • Theme preference persists across visits.

7) Voice

  • Write with founder-level ownership and concrete specificity.
  • Prioritize real status over promotional wording.
  • Use exact dates for release and rollout notes.
  • Keep private project details out of public pages.

8) Accessibility Baseline

  • Maintain clear focus states for navigation and buttons.
  • Keep heading hierarchy semantic and predictable.
  • Preserve lane contrast for readability.
  • Ensure mobile nav and card stacks remain legible under 48rem.
