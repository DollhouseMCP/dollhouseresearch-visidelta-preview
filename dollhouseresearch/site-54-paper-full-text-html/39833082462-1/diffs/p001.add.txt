## Fidelity
`fidelity-report.json` records 38 ordered comparisons with zero differences. The checker reads the actual PDF using `pdftotext -bbox-layout`. It compares the complete front matter, sections 1–7, Data Availability Statement, all six table captions and every column, Figure 1 caption, references 1–18, and submission history. It preserves numeric signs, decimals, intervals, operators, lexical hyphens, and order within each block.
Normalization covers whitespace, ligatures and mathematical italic alphabets, typographic quote/dash forms, PDF line-end hyphenation, and CCS bullets. Reading tools, navigation, duplicate visual equation text, running page headers, and page-layout float placement are excluded. Equations are read once through their accessible mathematical markup. This is a text comparison after typesetting normalization, not a claim that the HTML reproduces the PDF's two-column layout.
Figure 1 is a direct 5× raster extraction from PDF page 5, crop `(339, 82, 536, 163)` in PDF points. It is not redrawn from unpublished data. The image is linked at full size. Two reference URLs retain real line-end hyphens that the default PDF text reader incorrectly drops. One table cell lost its initial `18` during conversion; it was restored to the PDF's `18/18` and is covered by the comparison.
No known rendered-text gaps remain under this normalization. Exact source provenance remains open as described above. The existing talk-media holds are unchanged.
Run the comparison after building the site:
```sh
python3 scripts/check-paper-html.py \
  --html _site/research/sufficiently-advanced-agents/index.html \
  --pdf research/sufficiently-advanced-agents/paper-author-version.pdf \
  --report /tmp/paper-fidelity.json
```
The checker requires Python, Beautiful Soup, and Poppler's PDF text utility. It is specific to this eight-page paper and its fixed figure/table geometry.
