Dollhouse Collection

Dollhouse Collection is the community catalog for reusable Dollhouse elements.

It is where people discover, review, install, and publish composable building blocks used by DollhouseMCP.

Catalog Snapshot

The current collection library includes reusable content across all core types.

Element Type Count (Current Snapshot)
Personas 38
Skills 11
Templates 10
Agents 6
Memories 3
Ensembles 6

Example content in circulation includes:

  • personas like creative-writer, technical-analyst, and security-analyst
  • skills like code-review, threat-modeling, and research
  • templates like research-report and executive-summary
  • ensembles like development-team and security-analysis-team

How It Fits The Workflow

Collection is part of the everyday build loop, not a side repository.

  1. Discover content
  2. Install into local portfolio
  3. Adapt and version for your use case
  4. Re-submit improvements to the community catalog

Practical MCP-AQL Paths

Collection browsing and install flow is available directly from runtime operations:

  • browse_collection
  • search_collection
  • get_collection_content
  • install_collection_content

That means you can discover and install building blocks without leaving your active workflow.

What You Can Do In Minutes

  • Find a persona or skill that matches your immediate task
  • Install it into your portfolio without leaving your workflow
  • Open the element file and edit it directly
  • Publish your improved version back to the catalog

Why It Matters

Without a catalog, reusable AI behavior stays trapped in private notes and one-off prompts.

Collection gives teams:

  • a shared discovery surface
  • standardized metadata and validation patterns
  • faster reuse across projects
  • a practical path from local experiments to community-grade artifacts
