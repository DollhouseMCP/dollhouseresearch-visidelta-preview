Long (paragraph)

Dollhouse Research is the public brand and portfolio site for applied AI systems work from DollhouseMCP Inc (DBA Dollhouse Research). The portfolio spans core platform development, community distribution, protocol design, integration runtimes, and architecture research. Current priorities include DollhouseMCP, the Dollhouse Collection, MCP-AQL, Bridge, AILIS, and supporting tooling such as Merview. The objective is practical: ship systems that are technically strong, understandable to builders, and useful in real workflows.

Project One-Liners

  • DollhouseMCP: Open source MCP server for modular AI customization through reusable elements and persistent context.
  • Dollhouse Collection: Community catalog for browsing and reusing shared elements through a dedicated website.
  • MCP-AQL: Query and dispatch model for reducing tool-surface complexity in MCP operations.
  • Bridge: Integration runtime for connecting Dollhouse-powered sessions to external communication channels.
  • AILIS: OSI-inspired AI architecture language proposal for clearer cross-team system conversations.
  • Merview: Open source Markdown and Mermaid renderer for documentation and artifact review.
